# BATTLESHIP

A Battleship game played against the computer, built as part of the JavaScript curriculum in [The Odin Project](https://www.theodinproject.com/).

**[Play it live](https://zulu0824.github.io/Battleship/)**

## Features

- Both fleets are placed randomly each game
- Click the enemy board to fire, and a hit earns another shot
- The computer targets neighboring cells after a hit
- Sound effects for misses and hits
- Game over dialog with a play again option

The game does not yet support placing your own ships by drag and drop.

## Technologies used

1. HTML
2. CSS
3. JavaScript
4. Webpack
5. Jest
6. ESLint

## Running locally

    npm install
    npm start
    npm test
